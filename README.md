# PT-BR → PT-PT plugin for Subtitle Edit

A [Subtitle Edit](https://github.com/SubtitleEdit/subtitleedit) 5 plugin that converts Brazilian Portuguese
subtitles into European Portuguese (spelling, vocabulary and grammar). It is modelled on the official
[American to British](https://github.com/SubtitleEdit/plugins/tree/main/se5/AmericanToBritish) plugin and
uses the same layout, so the `se5/` folders can be dropped into the
[SubtitleEdit/plugins](https://github.com/SubtitleEdit/plugins) repository as they are.

- [`se5/BrazilianToEuropeanPortuguese`](se5/BrazilianToEuropeanPortuguese): the plugin. See its README for features and installation.
- [`se5/BrazilianToEuropeanPortuguese.Tests`](se5/BrazilianToEuropeanPortuguese.Tests): xUnit tests.
- [`se5/Plugin-Shared`](se5/Plugin-Shared): the shared SE5 plugin library, copied unchanged from SubtitleEdit/plugins.
